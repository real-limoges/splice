# Reference

**This is the only part of `docs/` that is committed.**
Everything else in the tree is gitignored, so nothing here may cite it: no links to sibling directories, no decision numbers, no finding IDs.
State what the reader needs in the document itself.

Reference material is split by who wrote it, because that decides how it may be changed.

| Directory | What Belongs There | How It Changes |
|---|---|---|
| [`external/`](external/) | Sources someone else wrote that this project cites | Never edited; a newer version replaces the file |
| [`internal/`](internal/) | Written here: architecture diagrams and how the system fits together | Describes `main`; rewritten in place |

Every document lives in one of the two.
A file directly in this directory, other than this README, is misfiled.
